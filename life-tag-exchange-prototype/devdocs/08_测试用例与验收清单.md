# 1. 测试目标

v0.2 起，验收目标不再是“每日 8 阶段按钮可以线性推进”，而是：

```text
玩家能在店铺主界面中，通过点击不同店铺区域，任意顺序完成每日经营闭环。
```

核心仍然必须验证：

```text
售价计算正确
爆雷区间正确
事故确定性结算正确
现金与累计利润分离
隐藏标签与暗风险不泄露
收店奖励形成构筑成长
Debug 面板可用于复现问题
```

---

# 2. 废弃测试

以下旧测试不再作为 P0：

```text
TEST_FLOW_001：按顺序推进 DAY_OPENING → DAY_PURCHASE → DAY_CUSTOMER → DAY_DRAW → DAY_PROCESS → DAY_SELL → DAY_RESOLVE → DAY_REWARD。
TEST_FLOW_002：禁止从 DAY_PROCESS 返回 DAY_DRAW / DAY_CUSTOMER / DAY_PURCHASE。
TEST_FLOW_003：DAY_SELL 返回 DAY_PROCESS。
```

原因：玩家可见 UI 不再使用阶段页。

# 3. 新增 P0 测试

## TEST_SHOP_001：主界面为店铺场景

步骤：

```text
1. 开始新局。
2. 查看主界面。
```

预期：

```text
显示 ShopScene。
显示公告牌、后门货源、订单板、牌盒、冷柜、砧板、收银台、账本、保险柜等区域。
不显示旧 8 阶段导航作为主流程。
```

## TEST_SHOP_002：公告牌生成新闻

步骤：

```text
1. 点击公告牌。
2. 查看新闻详情。
3. 再次点击公告牌。
```

预期：

```text
首次点击生成今日新闻。
重复点击不重刷新闻。
新闻效果显示清楚。
不泄露未揭示商品隐藏信息。
```

## TEST_SHOP_003：进货区生成商品候选且幂等

步骤：

```text
1. 点击后门货源。
2. 记录商品候选。
3. 再次点击后门货源。
```

预期：

```text
首次点击生成商品候选。
重复点击不重刷候选。
买入按钮受现金、库存上限、每日进货上限限制。
```

## TEST_SHOP_004：订单板生成顾客且幂等

步骤：

```text
1. 点击订单板。
2. 记录顾客订单。
3. 再次点击订单板。
```

预期：

```text
首次点击生成顾客订单。
重复点击不重刷订单。
顾客可用于交易预览选择。
```

## TEST_SHOP_005：牌盒抽牌且每日只抽一次

步骤：

```text
1. 点击牌盒。
2. 记录手牌数量。
3. 再次点击牌盒。
```

预期：

```text
首次点击抽今日手牌。
重复点击不重复抽牌。
牌盒可显示抽牌堆、弃牌堆、消耗堆。
```

## TEST_SHOP_006：任意顺序仍可完成每日经营

测试路径 A：

```text
牌盒 → 订单板 → 后门货源 → 公告牌 → 砧板 → 收银台 → 账本 → 保险柜
```

测试路径 B：

```text
公告牌 → 订单板 → 牌盒 → 后门货源 → 收银台 → 砧板 → 收银台 → 账本 → 保险柜
```

预期：

```text
两条路径都不报错、不刷重复内容、不导致状态错乱。
```

## TEST_SHOP_007：无库存点击砧板 / 收银台不报错

步骤：

```text
1. 新一天，不买入商品。
2. 点击砧板。
3. 点击收银台。
```

预期：

```text
显示空状态。
相关操作按钮 disabled。
disabled reason 说明没有库存商品。
控制台无错误。
```

## TEST_SHOP_008：交易预览常驻并刷新

步骤：

```text
1. 生成商品、顾客、手牌。
2. 选择商品、顾客、定价。
3. 使用鉴定 / 包装 / 公关 / 卡牌。
```

预期：

```text
DealPreviewDock 持续可见。
每次选择或加工后，预计售价、爆雷区间、事故预测刷新。
```

## TEST_SHOP_009：日结锁定当天经营

步骤：

```text
1. 点击账本并确认日结。
2. 再点击后门货源、牌盒、砧板、收银台。
```

预期：

```text
当天经营动作全部 disabled。
提示“今日已日结”。
不得继续进货、抽牌、加工、出售。
```

## TEST_SHOP_010：收店奖励进入下一天

步骤：

```text
1. 日结后点击保险柜。
2. 选择 / 购买奖励。
3. 完成收店。
```

预期：

```text
进入下一天。
新闻、商品候选、顾客订单、抽牌状态重置。
库存、被动、货源倾向、牌组按规则保留。
```

# 5. 发布前验收

```text
1. Chrome / Edge 可正常运行。
2. 新局可从第 1 天玩到第 8 天。
3. 店铺式主界面替代旧阶段页。
4. 任意顺序点击新闻、进货、订单、抽牌均可工作。
5. 日结与收店奖励仍能正确推进天数。
6. 第 8 天后正确显示胜负报告。
7. 控制台无阻塞错误。
8. Debug 面板可复现至少 3 条固定测试路径。
```
